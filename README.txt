台灣十六張麻將（手機電腦連線版）上線說明　製作：Eric Hu
================================================================

【這包裡有什麼】
  server.js            連線伺服器（房間、牌局、斷線重連、存檔）
  package.json         告訴 Render 要裝什麼、怎麼啟動
  package-lock.json    套件版本清單（一起上傳即可）
  .gitignore           告訴 GitHub 哪些資料夾不用管（可能看不到，是隱藏檔，沒傳也沒關係）
  shared/              牌局規則、電腦玩家、人物、卡牌（伺服器和畫面共用）
  public/              遊戲畫面：img 牌面圖片、chars 人物圖片、music 背景音樂

================================================================
第一步：整理 GitHub 上的 mahjong-server 儲存庫
================================================================
  舊檔案怎麼處理：
    game_manager.js        刪除
    mahjong_client.html    刪除
    rules_engine.js        刪除
    test_save_load.js      刪除
    test_save_load_live.js 刪除
    package.json           保留，等一下上傳新的會直接蓋掉
    server.js              保留，等一下上傳新的會直接蓋掉

  刪除一個檔案的方法（五個檔案各做一次）：
    1. 在儲存庫首頁點檔名，例如 game_manager.js
    2. 右上角按「…」（三個點）→ 選 Delete file
    3. 按綠色的 Commit changes… → 再按一次 Commit changes

================================================================
第二步：上傳新檔案（因為 GitHub 一次最多傳 100 個檔案，分兩次）
================================================================
  先把這個壓縮檔解壓縮到電腦上。

  第一次：上傳 public 資料夾
    1. 回到儲存庫首頁，按「Add file」→「Upload files」
    2. 從檔案總管把「public」整個資料夾拖進網頁的框框
       （要拖資料夾本身，不要點進去選檔案，這樣資料夾結構才會保留）
    3. 等下面的清單全部跑完，按 Commit changes

  第二次：上傳其他全部
    1. 再按一次「Add file」→「Upload files」
    2. 把「shared」資料夾，還有 server.js、package.json、package-lock.json、.gitignore、README.txt 一起拖進去
    3. 按 Commit changes

  完成後儲存庫首頁應該看到：public、shared 兩個資料夾，和 server.js、package.json 等檔案。
  點進 public 應該看到 img、chars、music 三個資料夾和 index.html 等檔案。

================================================================
第三步：申請免費資料庫 Neon（讓存檔永久保存）
================================================================
  為什麼需要：Render 免費方案每次重新部署、重新啟動，伺服器上的檔案都會清空；
  Render 自己的免費資料庫 30 天後會被刪掉。Neon 的免費方案不會過期，資料不會被刪，
  容量 0.5 GB，一份存檔只有幾十 KB，存幾千個玩家都夠。

  1. 打開 https://neon.com ，按 Sign up，可以直接用 GitHub 帳號或 Google 帳號登入
  2. 第一次進去會叫你建立專案（Create project）：
       Project name：mahjong（隨便取）
       Postgres version：用預設
       Region：選和 Render 伺服器相近的地區
         （Render 服務頁面左上方會寫地區；Singapore 就選 Singapore，Oregon 就選 US West (Oregon)）
       按 Create project
  3. 建好後在專案首頁按「Connect」按鈕
  4. 跳出的視窗裡有一串以 postgresql:// 開頭的文字，那就是「資料庫連線網址」
     按旁邊的複製圖示（如果密碼被遮住，先按 Show password 再複製）
  ※ 這串網址裡有密碼，只能貼到 Render 的設定裡，不要貼進 GitHub 的任何檔案，也不要傳給別人。

================================================================
第四步：把資料庫接到 Render
================================================================
  1. 打開 Render，點進 mahjong-server 這個服務
  2. 左邊選 Environment
  3. 按 Add Environment Variable（或 Edit → Add），填：
       Key（名稱）：DATABASE_URL
       Value（內容）：貼上第三步複製的那串網址
  4. 按 Save（如果有選項，選 Save, rebuild, and deploy）

================================================================
第五步：部署與確認
================================================================
  1. Render 在 GitHub 有新檔案時會自動部署；如果沒動，按右上角 Manual Deploy → Deploy latest commit
  2. 左邊選 Logs（紀錄），等看到這兩行就是成功：
       麻將伺服器啟動於連接埠 ……，存檔方式：資料庫
       資料庫連線成功
     如果寫「存檔方式：伺服器檔案」→ 第四步的 DATABASE_URL 沒設好
     如果寫「資料庫暫時連不上」→ 網址貼錯，回 Neon 重新複製再貼一次
  3. 用手機和電腦打開 https://mahjong-server-f5nc.onrender.com
     （免費方案閒置後會休眠，第一次打開可能要等大約一分鐘）
  4. 測試存檔：電腦按「存檔／讀取進度」→ 輸入暱稱和生日 4 碼 → 存檔
     再用手機打開同一個網址 → 同一個暱稱和密碼 → 讀取進度，看進度有沒有過來

================================================================
【怎麼玩】
================================================================
  ・單人模式：對 1～3 位電腦（雙人桌、三人桌、四人桌），在瀏覽器裡打
  ・冒險模式：單人闖關，拿遺物、卡牌、金幣
  ・對戰模式：按「建立對戰房間」選模式
       雙人對戰（2 真人）、雙人＋2 電腦、三人對戰（3 真人）、三人＋1 電腦、四人對戰（4 真人）
    建立後會得到四位數房號，按「複製邀請連結」傳給朋友（LINE 也可以）
    朋友點連結或輸入房號加入；真人到齊才能開始，房主可以在房間裡切換模式
  ・座位：雙人桌是上下兩家；三人桌是左、下、右
  ・斷線了重新打開網址就會回到原本的座位；斷線期間由電腦代打
  ・存檔：暱稱＋4 碼密碼（建議生日月日）。同一個暱稱只能用第一次設的密碼；
    密碼連錯 5 次會鎖 10 分鐘

【注意】
  ・伺服器重新啟動時，進行中的牌局會中斷（存檔不受影響）
  ・手機建議橫放
